Identity Attack Graph

Graph-based identity attack path analysis

Feed it a security dataset. Get back the paths an attacker would take, the blast radius of any identity, and the exact set of changes that would cut every path.

No signup needed to explore the demo. Login required only to upload your own data.

Universal ingestion

Drop in a BloodHound export, a ZIP of CSVs, or a single JSON file. The schema profiler figures out what each table means and shows you the mapping before anything is committed.

Real attack paths

Not just a graph — the engine enumerates distinct attack strategies, ranks them by severity, and explains each hop in plain English with MITRE technique tags.

Actionable mitigations

The min-cut solver finds the minimum set of edges whose removal severs every path from a compromised identity to your crown jewels. Not "here are 400 findings" — "change these 2 things."

Blast radius

Click any identity to see every node, credential, machine, and asset it can reach — ranked by criticality and hop count.

Provenance

Every edge is traceable back to the source file and row that produced it. Nothing is fabricated. If the data doesn't say it, the graph doesn't contain it.

Change tracking

Snapshot a dataset now, import the next collection later, and get a diff: new escalation edges, new memberships, and the fixes that actually worked.

How it works

  1. Import — upload a security dataset (BloodHound, CSV, JSON).
  2. Review — see how the profiler interprets each file. Edit the mapping if needed.
  3. Analyse — click an identity, select crown jewels, and compute attack paths.
  4. Fix — let the min-cut solver tell you the cheapest changes that sever every path.
  5. Track — snapshot now, re-import later, and diff the two.
