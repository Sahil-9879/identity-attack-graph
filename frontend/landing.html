Features

Everything you need to reason about identity risk

01

Enumerate attack paths

From any compromised identity to any crown jewel. Ranked by severity, annotated with MITRE technique IDs, and explained hop by hop.

02

Blast radius

Click any identity to see every node, credential, machine, and asset it can reach — sorted by criticality and hop count.

03

Optimal mitigation

The min-cut solver finds the minimum set of changes that disconnects source from every target. Not "400 findings" — "change these 2 things."

04

Provenance on every edge

Trace any relationship back to the source file and row. Nothing is fabricated — if the data doesn't say it, the graph doesn't contain it.

05

Change tracking

Snapshot now, re-import next month, and diff. New escalation edges, new memberships, and the fixes that actually worked.

06

Export a report

Markdown or print-ready HTML. Executive summary, top paths, the mitigation plan, and per-hop annotations.

How it works

Five minutes from raw data to a decision

  1. 01

    Import

    Upload a BloodHound SharpHound export, a ZIP of CSVs, or a single JSON environment. Format detection is automatic.

  2. 02

    Review the mapping

    The schema profiler inspects every file's columns, decides what each table means, and shows you the interpretation with a confidence score. Nothing is committed until you approve.

  3. 03

    Analyse

    Click any identity to mark it compromised. Shift-click any asset to select it as a target. Enumerate paths, compute blast radius, find chokepoints.

  4. 04

    Fix

    Let the min-cut solver propose the cheapest changes that sever every path. Apply them in the app and watch the graph update live.

  5. 05

    Track

    Snapshot the graph. Re-import next month. Diff the two to see what changed and which fixes held.

Recommended

BloodHound / SharpHound

The standard AD attack-path format. Collect with SharpHound, upload the ZIP. The parser reads the Aces field on every object — the real ACL graph with GenericAll, WriteDacl, DCSync, and 17 other primitives.

Any structured data

CSV / JSON / ZIP

Upload a ZIP of CSVs, a single JSON document, or a flat CSV of relationships. The profiler figures out what each file means from column names, sample values, and cross-file references.
